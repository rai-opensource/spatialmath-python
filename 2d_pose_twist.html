se(2) twist

class Twist2(arg=None, w=None, check=True)[source]

Bases: BaseTwist

2D twist class

A Twist2 object holds the parameters of a twist, a representation of a 2D rigid body transformation which is the unique elements of the Lie algebra se(2) of the corresponding SE(2) matrix. It is a 3-vector \([\vec{v}, \omega]\).

As for Twist3 it can be used as a displacement, where exp(S) is the pose reached by following the motion, or as a velocity, where exp(S * dt) is the pose change over a time dt. Properties that describe the axis, such as pole, are unchanged by scaling the twist.

classmethod Alloc(n=1)

Construct an instance with N default values (BasePoseList superclass method)

Return type:

Self

Returns:

pose instance with n default values

X.Alloc(N) creates an instance of the pose class X with N default values, ie. len(X) will be N.

X can be considered a vector of pose objects, and those elements can be referenced X[i] or assigned to X[i] = ....

Note

The default value depends on the pose class and is the result of the empty constructor. For SO2, SE2, SO3, SE3 it is an identity matrix, for a twist class Twist2 or Twist3 it is a zero vector, for a UnitQuaternion or Quaternion it is a zero vector.

Example:

>>> x = X.Alloc(10)
>>> len(x)
10

where X is any of the SMTB classes.

Ad()[source]

Adjoint of 2D twist

Returns:

adjoint matrix

Return type:

ndarray(3,3)

S.Ad() is the 3x3 adjoint matrix of the corresponding homogeneous transformation.

For a twist representing motion from frame {B} to {A}, the adjoint will transform a twist relative to frame {A} to one relative to frame {B}.

Example:

>>> from spatialmath import Twist2
>>> S = Twist2([1, 2, 0.3])
>>> S.Ad()
array([[ 0.9553, -0.2955,  2.119 ],
       [ 0.2955,  0.9553, -0.6873],
       [ 0.    ,  0.    ,  1.    ]])

Note

This method computes the equivalent SE(2) matrix, then the adjoint of that.

Seealso:

Twist2.ad(), Twist2.SE2(), Twist2.exp()

__init__(arg=None, w=None, check=True)[source]

Construct a new 2D Twist object

return:

2D twist

rtype:

Twist2 instance

  • Twist2(R) is a 2D Twist object representing the SO(2) rotation expressed as a 2x2 matrix.

  • Twist2(T) is a 2D Twist object representing the SE(2) rigid-body motion expressed as a 3x3 matrix.

  • Twist2(X) if X is an SO2 instance then create a 2D Twist object representing the SO(2) rotation, and if X is an SE2 instance then create a 2D Twist object representing the SE(2) motion

  • Twist2(V) is a 2D Twist object specified directly by a 3-element array-like comprising the moment vector (2 elements) and direction vector (1 element).

References:

  • Robotics, Vision & Control for Python, Section 2.2.2.4, P. Corke, Springer 2023.

  • Modern Robotics, Lynch & Park, Cambridge 2017

Note

Compared to Lynch & Park this module implements twist vectors with the translational components first, followed by rotational components, ie. \([\vec{v}, \omega]\).

ad()[source]

Logarithm of adjoint of 2D twist

Returns:

logarithm of adjoint matrix

Return type:

ndarray(3,3), or list of ndarray if the twist is a sequence

S.ad() is the 3x3 matrix representation of the Lie bracket with the twist S, such that for twists S and T

\[\mathrm{ad}(S) \vec{T} = \vee \left( [S] [T] - [T] [S] \right)\]

where \([S]\) is the augmented skew-symmetric matrix of the twist. For \(S = (v_x, v_y, \omega)\) it is

\[\begin{split}\begin{pmatrix} 0 & -\omega & v_y \\ \omega & 0 & -v_x \\ 0 & 0 & 0 \end{pmatrix}\end{split}\]

Example:

>>> from spatialmath import SE2, Twist2
>>> T = SE2(1, 2, 0.3)
>>> S = Twist2(T)
>>> S.ad()
array([[ 0.    , -0.3   ,  1.835 ],
       [ 0.3   ,  0.    , -1.2925],
       [ 0.    ,  0.    ,  0.    ]])

Note

An alternative approach to computing the adjoint is to exponentiate this 3x3 matrix.

Seealso:

Twist2.Ad()

exp(theta=1, unit='rad')[source]

Exponentiate a 2D twist

Parameters:

  • theta (float, optional) – rotation magnitude, defaults to 1

  • unit (str, optional) – rotational units, defaults to ‘rad’

Returns:

SE(2) matrix

Return type:

SE2 instance

  • X.exp() is the homogeneous transformation equivalent to the twist, \(e^{[S]}\)

  • X.exp(θ) as above but with a rotation of θ about the twist axis, \(e^{\theta[S]}\)

Example:

>>> from spatialmath import SE2, Twist2
>>> T = SE2(1, 2, 0.3)
>>> S = Twist2(T)
>>> S.exp(0)
SE2(array([[1., 0., 0.],
           [0., 1., 0.],
           [0., 0., 1.]]))
>>> S.exp(1)
SE2(array([[ 0.9553, -0.2955,  1.    ],
           [ 0.2955,  0.9553,  2.    ],
           [ 0.    ,  0.    ,  1.    ]]))

Note

  • For the second form, the twist must, if rotational, have a unit rotational component.

skewa()[source]

Convert 2D twist to se(2)

Returns:

An se(2) matrix

Return type:

ndarray(3,3)

X.skewa() is the twist as a 3x3 augmented skew-symmetric matrix belonging to the group se(2). This is the Lie algebra of the corresponding SE(2) element.

Example:

>>> from spatialmath import Twist2, base
>>> S = Twist2([1,2,3])
>>> se = S.skewa()
>>> se
array([[ 0., -3.,  1.],
       [ 3.,  0.,  2.],
       [ 0.,  0.,  0.]])
>>> base.trexp2(se)
array([[-0.99  , -0.1411, -1.2796],
       [ 0.1411, -0.99  ,  0.7574],
       [ 0.    ,  0.    ,  1.    ]])
